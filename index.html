Verified In This Repository C++17 POSIX Sockets Multithreading

Multithreaded C++ HTTP Server

Raw POSIX socket networking, worker thread pool & concurrent client scheduling
Inspect Source Code

Rather than relying on high-level HTTP abstractions, I implemented this server from scratch using fundamental POSIX socket calls: socket(PF_INET, SOCK_STREAM, 0), bind(), listen(), and accept(). The goal was to understand the mechanical reality of the TCP handshake, socket descriptors, and HTTP protocol serialization.

Concurrency Architecture: A common naive approach spawns or detaches a thread for every single connection. Under high traffic, this exhausts memory and thrashes the kernel scheduler with context switches. Instead, I designed a fixed-capacity Thread Pool of 4 worker threads feeding off a synchronized task queue:

  • ✔ Producer-Consumer Queue: Main thread accepts connection descriptors and enqueues them.
  • ✔ Mutex & Condition Variable: Workers sleep on std::condition_variable until signaled, preventing 100% CPU busy-wait spinning.
  • ✔ Clean Shutdown Protocol: Mutex-protected shutdown flag + notify_all() for clean thread joining.
  • ✔ RFC Response Framing: Parses request path, sets appropriate Content-Length & streams file contents over raw socket.

Current Learning Trajectory: Extending the request parser to handle HTTP headers robustly, preventing directory traversal attacks via sanitized file path slicing, and benchmarking against epoll/kqueue event loops.

C++ Operating Systems Filesystem Internals

ext2 Filesystem Exploration Utility

An inspection and forensic utility written in C++ to parse, traverse, and inspect unmounted raw ext2 filesystem disk images directly at byte-level offsets without relying on OS kernel mounts.

Internal Architecture & Data Structures
  • • Superblock Parsing: Extracts magic number 0xEF53, block size (1024 << s_log_block_size), inode totals, and free block bitmaps.
  • • Inode Table Traversal: Reads file modes, UID/GID, size, and traverses 12 direct block pointers plus single, double, and triple indirect pointers.
  • • Directory Entries: Walks variable-length ext2_dir_entry_2 linked structures to resolve hierarchical paths (e.g., /var/log/syslog) manually.

C++ Data Structures Memory & Cache

High-Performance LRU File Cache

An in-memory Least Recently Used (LRU) buffer cache designed to sit in front of disk-bound I/O pipelines, achieving guaranteed O(1) lookups and O(1) evictions under strict memory capacity constraints.

Internal Architecture & Data Structures
  • • Hash Map + Doubly Linked List: std::unordered_map for O(1) key lookup referencing iterators in a std::list of cached memory blocks.
  • • Byte-Budget Eviction: Tracks actual byte allocation footprint rather than simple entry count, preventing out-of-memory errors on large payload files.
  • • Thread Safety: Evaluated reader-writer locks (shared mutex) to minimize lock contention during high-read concurrency compared to single global locks.
